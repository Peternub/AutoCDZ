# AutoCDZ

Закрытый прототип Telegram-бота на Python 3.13 и aiogram 3. SQLite хранит состояние между перезапусками. Администрирование осуществляется в Telegram.

## Что работает

- Регистрация через `/start`, главное меню и поддержка.
- Сохранение настройки уведомлений.
- Тестовые подписки: выдача, продление, проверка истечения срока.
- `/admin`: количество пользователей и активных тестовых подписок.
- `/grant ID ДНИ`: выдача тестового доступа администратором, срок 1–365 дней.
- `/delete_me`: удаление собственных данных с подтверждением.
- Работа только в личных чатах, ограничение административных команд по Telegram ID.

## Что ещё не реализовано

Подключение МЭШ, получение ЦДЗ, ИИ-решения, фоновые проверки, отправка ответов, платежи Tribute, промокоды, возвраты и веб-панель. Разделы МЭШ и автоматизации показывают реальную недоступность. Демо-задания и фиктивные статусы выполнения не создаются. Продажа подписок отключена; `/grant` выдаёт только тестовый доступ, не подтверждает оплату.

По согласованию с владельцем сначала реализован интерфейс без интеграции МЭШ. Это основа для дальнейшей разработки, а не готовый MVP из полного ТЗ. Следующий этап требует документации согласованного интерфейса МЭШ и параметров ИИ-провайдера. Для Tribute потребуются параметры продукта и механизм проверки платежей; одной ссылки недостаточно.

## Локальный запуск в Windows

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.lock.txt
Copy-Item .env.example .env
# Заполните .env своим токеном и ID администратора.
.\.venv\Scripts\python -m autocdz
```

Если `.env` уже заполнен, не перезаписывайте его. Настройки читаются из окружения или `.env`. Не публикуйте этот файл. Если токен стал доступен посторонним, перевыпустите его через BotFather и замените в `.env`.

| Настройка | Назначение |
| --- | --- |
| `BOT_TOKEN` | Токен Telegram-бота |
| `ADMIN_ID` | Telegram ID единственного администратора |
| `DATABASE_PATH` | Путь к базе, по умолчанию `data/autocdz.db` |
| `SUPPORT_URL` | Необязательная HTTPS-ссылка на поддержку |
| `TRIBUTE_URL` | Резерв для будущей интеграции; оплата сейчас отключена |

Сначала отправьте боту `/start`, затем `/admin`. Чтобы выдать себе неделю тестового доступа, используйте `/grant ВАШ_ID 7`. Пользователь должен быть зарегистрирован. Все даты подписок показываются по московскому времени.

## Круглосуточный запуск на VPS

На Linux-сервере с Docker Compose:

```sh
git clone https://github.com/Peternub/AutoCDZ.git
cd AutoCDZ
cp .env.example .env
# Заполните .env на сервере.
docker compose up -d --build
docker compose logs --tail 50 bot
```

Контейнер перезапускается автоматически. База находится в постоянном томе `bot_data`; не удаляйте его при обновлениях. Нельзя запускать два экземпляра опроса с одним токеном. Установленный webhook нужно отключить перед запуском; бот не удаляет его автоматически. Docker-сборка требует проверки на сервере с установленным Docker.

Для обновления остановите локальный экземпляр, если он использует тот же токен, и выполните на сервере:

```sh
git pull --ff-only
docker compose up -d --build
```

## Проверка

```powershell
.\.venv\Scripts\python -m unittest discover -s tests -v
.\.venv\Scripts\python -m compileall -q autocdz tests
```

Тесты не обращаются в Telegram: проверяют права администратора, запрет работы в группах, удаление только собственных данных, сохранение базы после перезапуска, продление и истечение подписки.

До публичного запуска необходимы интеграция МЭШ, политика обработки данных, условия услуги и полноценная проверка требований исходного ТЗ. Содержимое заданий и учётные данные МЭШ в этой версии не собираются.
